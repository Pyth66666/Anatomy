# Veterinary atlas credits and coverage

Added to Anatomy 360 on 2026-10-29 as a separate viewer.

## Source

- Viewer and model distribution: https://github.com/JorgeTAC/vet-anatomy-viewer (main archive retrieved 2026-10-29).
- Original model attribution retained from that repository: **Virginia Tech Virtual Animal Project / VT-ARIES — CC BY-NC-SA 4.0**.
- Original project: https://virtualanimalproject.vetmed.vt.edu/
- Model license: https://creativecommons.org/licenses/by-nc-sa/4.0/
- Upstream declares its own viewer code MIT; its original README is retained as UPSTREAM.md. The downloaded archive does not include a separate MIT license file.

The anatomy data has its own license, separate from the human atlas. Preserve attribution, noncommercial restrictions and ShareAlike terms for the model data and adaptations. Do not treat the parent repository's code license as a license for these models.

## Changes

English interface, Anatomy 360 navigation and styling, explicit coverage notes, improved loading and errors, nested-mesh selection, visible-only picking and camera fitting. No upstream service worker is registered: this section does not take control of the human viewer or its caches. Human atlas data and viewer scripts are independent.

## Included coverage

- Canine: 138 source model pieces; skeletal regions and organs.
- Equine: 208 source model pieces; skeletal regions, organs, muscles, nervous and vascular structures.
- Bovine: 54 source model pieces; skeletal regions.

Counts refer to files, not a verified count of distinct anatomical structures. Collections are incomplete and differ in coverage. Original model names are preserved, including possible spelling mistakes or uncertain labels. No independent anatomical validation has been performed. Cats and other species are not included.
